# 🌸 Sweet POS System

A pink-themed, minimalist Point of Sale (POS) web application built with **CodeIgniter 4** and **MySQL**, designed for smooth inventory management, customer tracking, and sales reporting.

---

## ✨ Features

* **🎀 Pink Minimalist Aesthetic**: Clean and user-friendly UI styled with soft pastel pink themes.
* **📦 Product Management**: Add, update, and monitor product stock levels in real-time.
* **👥 Customer Directory**: Keep track of customer purchases and details.
* **👩‍💼 Staff & User Tracking**: Record which staff member processed each sale transaction.
* **🛒 Sales Recording**: Seamlessly process transactions, calculate total prices, and deduct stock automatically.
* **📊 Sales History**: View a complete breakdown of past transactions, quantities, prices, and timestamps.

---

## 🛠️ Tech Stack

* **Backend**: PHP (CodeIgniter 4 Framework)
* **Database**: MySQL / MariaDB (phpMyAdmin)
* **Frontend**: HTML5, CSS3, Bootstrap, Custom Styling
